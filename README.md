## Project Overview 

A website I completed whilst learning React and it's based on a hobby of mine which is guitar. It was designed with a home page with a quiz for users to get a rough estimate of what level they are at, guitars and amps with specification list for all listed and categorised by brand. 

A year later I came back to the project to create an online guide for guitarists who may feel stuff on their learning journey providing full guides from beginner to advanced.

## Features

- Mobile Optimisation
- Intuitive Design
- Mathematical Operations
- PropTypes React Library
- useState Functions

## References to sites I have used 

The amps and guitars included are all from https://www.thomann.co.uk/ which is the site I used to buy my electric guitar
